# Damage icons

Original Warframe text icon assets, copyright Digital Extremes. Retrieved via [browse.wf Text Icons](https://browse.wf/text-icons), using the DIT_AUTO paths in [ExportTextIcons.json](https://github.com/calamity-inc/warframe-public-export-plus/blob/senpai/ExportTextIcons.json). See also [Warframe Wiki: Damage](https://wiki.warframe.com/w/Damage). These assets are third-party game artwork, not relicensed under this repository's MIT license. The UI uses the original alpha masks for monochrome display and the report renderer uses the same masks. No runtime network access. 

Build-time downloader: `scripts/fetch_damage_icons.py`. Exact source URLs: `damage-icons.json`. The generated manifest records the downloaded file hashes.
